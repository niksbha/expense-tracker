# Expense Tracker
Web prototype (single HTML file) that is the design reference for the future Expo mobile app.
- `src/` numbered parts; `./build.sh` joins them into `dist/expense-tracker.html`
- `tests/` node harnesses (stubbed DOM)
- Version in `VERSION`, history in `CHANGELOG.md`; release = bump VERSION, update CHANGELOG, commit, `git tag vX.Y.Z`
